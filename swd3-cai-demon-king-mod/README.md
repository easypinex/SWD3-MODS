# 蔡魔王挑戰

**v1.8，2026-09-08。** 採用使用者已認可的短節奏戰鬥，補齊重戰、懷舊、回血與配裝線索分支，以及可觀察異常的公平比試檢查。新增內容先通過靜態、mock與封裝檢查；實機狀態以[驗收](TESTING.md#v18-第一階段物理覆蓋)為準。這是《軒轅劍參》Steam高清版4.0.x的遊戲MOD。

[Steam 工作坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3798055142)｜[本次發佈核對](release/steam-workshop/AUDIT-20260908.md)

## 使用與範圍

啟用`cai_demon_king.ssmod`並完整重啟遊戲，在物品欄按 **Insert → 開始挑戰**。資訊列可查看招式規則與比試規格；選單只有功能文字，角色台詞全部在戰鬥內出現。

- 最多四名主角，以既有隊伍參戰。入場恢復生命、靈力、體力及絕招能量，解除死亡與異常。
- 正常勝利、敗北及中止後，還原入場前的角色資源／異常／絕招能量；戰中確實扣除的道具於離場後返還。戰鬥中仍須支付費用，沒有即用即補。
- 依使用者實機確認，本挑戰中的護駕不會死亡或耗損；召喚仍須支付體力，並另備背包中的可用護駕。
- 挑戰次數與敗北線索輪替會隨目前存檔正常保存；不自動存檔、不替換劇情隊員、不直接編輯存檔檔案。新版本從首次有效入場開始計數，不猜測舊版歷史。
- 戰勝時若尚未持有「蔡魔王・真契靈」，取得一份獎勵；背包、裝備、預留及本場待返還份額都算持有。已有者不重複發放，場外失去後可再戰補領。確認實際發放後，戰後另顯示獎勵通知，返回物品欄時走原生重建流程；新流程實機待驗。

效果點數不是固定實際扣血。回血占正常選招，可能被中斷；回血與封技不跳過循環中的普攻位置；前段重劍後的普攻緩衝也跨階段保留。光劍有其他存活主角可選時避開上一重劍目標。此版延續已認可的戰鬥基礎，新增前段物理節奏仍待人工回歸，不加入舊稿尚未驗證的「循環惡夢」蓄勢／收勢流程，也不保證固定玩家行動窗口。

完整終局配裝與正常取得條件見[配裝整備](LOADOUT-AND-TESTING-SETUP.md)、[護駕與材料鏈](GUARDIAN-SUPPLY-AND-AI.md)。

## 對話與公平比試

正式入口可觸發34句，以懷舊與回望DOMO同伴、玩家當年的旅程為主，保留蔡魔王嚴謹而溫和的人設。一般每場最多六句：初遇、四種短重戰開場、第三次起30%較長往事分支、真契靈同行、階段／回血時的回憶、四組敗北配裝線索，以及互斥的勝利結尾。所有台詞均為MOD原創角色對白。全文及觸發條件見[對話表](DIALOGUE.md)。v1.1以公開訪談與近況改寫19句，取材包含同事出遊、宣紙手稿、音樂製作、經典移植與玩家來信，見[訪談來源](DIALOGUE-SOURCES.md)。

[公平比試](FAIR-PLAY.md)包含主角入場上限、戰中背包數量對帳與本MOD專用資料檢查。確實觸發時中止比試，不計勝利、不發獎，正常還原流程仍執行；單敵戰先說對應台詞，混編維持靜默。高數值只代表超出本場規格，不代表一定使用修改器。

**不宣稱能偵測所有修改器。** 鎖血、鎖靈力、改寫實際傷害／秒殺及繞過Lua的工具仍無可靠全覆蓋。沒有「單下9000以上即作弊」規則，不把兩次HP採樣差額當單次傷害，也不因正常使用真夢娃娃或高抗性而判作弊。

## 相容性

本體不依賴挑戰模式、全魔物靈契、玩家AI或四人測試開局；不包含測試發物／隊伍建立程式。本機原有測試輔助包可另行保留，並非正式發行內容。

- 全魔物靈契：保留來源438與舊10096卡的既有修補；Insert對手11001及勝利獎勵11006獨立。搭配F9 v0.9時，選原438映射11001，可自由混編；一名敵人保留台詞，多名敵人全部靜默。保留正式策略及F9倍率／獎勵門檻，每名蔡魔王獨立階段與一次回血。F9 v0.8以前未整合，仍是原版438。
- 玩家AI測試包：本體Insert選單不再提供手動召喚接手入口。原有測試包若仍啟用，開始挑戰仍會套用它的主角AI；該包亦會啟用全域原生AI介面，不能當本體預設功能。本機已於v1.7依使用者選擇停用AI測試包，恢復手動戰鬥。
- 四人滿裝測試開局：即使已有測試存檔標記，也不再顯示補給入口。正式包不帶這個開局，也不會自行補裝備。
- 熟練倍率與煉化解除：不以是否安裝這些MOD判作弊；仍須遵守本場入場規格與正常戰中數量異動。
- 與`cai_act_probe.ssmod`互斥。直接改寫同一專用資料或不串接物品函式的MOD可能被拒絕，沒有保證任意MOD組合相容。

持有自訂真契靈的存檔請保留本MOD。停用時優先讀取取得獎勵前的備份；新卡裝備、保存／完整重啟及停用矩陣仍依[驗收](TESTING.md#v18-第一階段物理覆蓋)，不宣稱已全面通過。
