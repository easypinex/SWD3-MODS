在原生物品欄按 `F9`，進入由遊戲引擎繪製與操作的「挑戰模式」選單。選 1～5 張活物作為敵方；選取的持有卡不會消耗。難度平均達 `1.0x` 時保留原版獎勵；低於 `1.0x` 才是無獎勵練習模式。

## 操作

原生選單接管方向鍵、確認鍵與滑鼠列選取。每個子選單的首列與末列都固定為「返回上層」，怪物與種族清單每頁最多 7 筆；點選空白處可安全返回。主選單的「返回物品欄」則結束挑戰模式。`Esc` 已實測不會返回，也不會進入 MOD 的事件記錄，因此目前不是可用快捷鍵。

| 選單項目 | 用途 |
| --- | --- |
| 我的活物 | 從目前持有、資料完整的活物中選卡；同一張可重複選，受可用數量限制。 |
| 神魔異事錄（依種族） | 依原版種族篩選圖鑑中的完整戰鬥資料；不要求玩家持有或具備 `IT_12`。 |
| 特殊／首領 | 劇情／圖鑑外的完整戰鬥活物，例如不可取得的首領；同樣不要求 `IT_12`。 |
| 已選隊伍 | 顯示目前 1～5 張選擇；可逐張移除或清空。 |
| 難度調整 | 分別調整生命、攻擊傷害、防禦、速度與技能傷害；每項可從 0.5x 到 2.0x、每次 0.1x，初始都是 1.0x。 |
| 開始挑戰 | 建立敵方隊伍並啟動原生戰鬥。 |

所有難度項目的算術平均值 `>= 1.0x` 時，才沿用原版獎勵；平均值低於 `1.0x` 時，本次挑戰仍可開始，但不發放經驗、金錢、法寶經驗、絕招經驗或一般掉落。例如生命 `0.9x`、攻擊傷害 `1.1x`、其餘 `1.0x` 時，平均仍為 `1.0x`，可保留獎勵。選單會顯示目前平均係數與無獎勵提示。隊伍與難度會在關閉選單、進戰和戰後保留；完整重啟遊戲才會回到空隊伍與全數 `1.0x`。

物品欄進入、離開原生選單後會重設反白、分類與使用中的暫態狀態。這是遊戲選單重建的既有行為，MOD 不會改變背包內容或存檔。

## 資料與安全規則

- 持有卡只增加暫時的 `Stock` 預留；不扣 `Count`／`Count_New`，戰鬥結束、戰敗、逃跑、切圖與重新開局都會釋放預留。
- 神魔異事錄與特殊／首領是虛擬敵人，沒有背包預留。
- 「我的活物」要求 `IT_12`；虛擬敵人只要求 `isBattleChar`、正整數 `ACT` 與正整數 `Level`。因此撒旦賽特等異事錄首領會列出，但不會被誤當成可持有物品。
- 對挑戰敵人收妖時，若原版新增同 ID 活物，MOD 只移除本次新增的一張，避免複製選取卡；但若「全魔物靈契」已武裝且目標位於其靜態卡庫，來源物會保留給該 MOD 在戰後交換成映射靜態卡，避免兩個 MOD 重複處理同一筆原生新增物。
- 難度只改本次挑戰的敵方戰鬥資料：生命（含最大生命）、攻擊、防禦、速度與智慧。攻擊傷害與技能傷害分別對應 `ATK`／`WIS`；不同技能的實際傷害公式仍由原生引擎決定，須依 `TESTING.md` 實機確認。
- 難度平均值低於 `1.0x` 時，MOD 會在這場戰鬥暫時清空敵人的 `GainEXP`、`GainGold` 與一般掉落資料，並在勝敗、逃跑、換圖、讀檔或開戰失敗時精確還原；`BattleGain` 結算值也會歸零。
- 顯示名稱會經 `StringDB` 轉成遊戲的中文名稱，不顯示 `ItemName127` 這類資料鍵。
- 怪物與種族長清單每頁最多 7 筆；加上首尾固定「返回上層」及翻頁列後，仍維持容易點選的高度。
- `ESC.Menu` 的每個選項會由 MOD 自動加入不可見的 UTF-8 尾端空白緩衝，避免引擎破壞中文字尾端；新增選項必須走既有 `nativeMenu` 包裝，不能直接呼叫 `ESC.Menu`。
