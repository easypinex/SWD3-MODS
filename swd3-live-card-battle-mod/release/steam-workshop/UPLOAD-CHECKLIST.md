# SWD3Works／Steam 工作坊上傳清單

這是 `live_card_battle` v0.6 的上傳清單。上傳前請先讀 [發布素材包](README.md)。

## 應選擇的檔案

- 內容資料夾：`workshop_content`
  - 只包含 `live_card_battle.ssmod`。
- 主要預覽圖：`preview/live-card-battle-workshop-primary-preview.jpg`（1024 × 1024、256,027 bytes）。
- 標題：複製 `TITLE-ZH-TW.txt`。
- 說明：複製 `DESCRIPTION-ZH-TW.txt`。
- 更新說明：複製 `CHANGE-NOTE-v0.6.txt`。

## 建議上傳順序

- [ ] 使用 `SWD3Works.exe` 建立工作坊項目，先設為私人或僅限好友。
- [ ] 內容資料夾選 `workshop_content`，預覽圖選 `preview` 內的 JPEG。
- [ ] 貼上標題、完整說明與更新說明。
- [ ] 上傳後取消訂閱再重新訂閱，確認 Steam 實際下載資料夾只包含預期 `.ssmod`。
- [ ] 在 MOD 管理停用再啟用，然後完整關閉並重開遊戲。

## 公開前最低實機驗收

- [ ] F9 文字、清單、返回與滑鼠操作正常。
- [ ] 隊伍與難度在關閉選單、進戰、戰後重新開啟 F9 時保留；完整重啟後重設。
- [ ] 以 `0.5x`／`1.0x`／`2.0x` 實測生命、攻擊、防禦、速度與技能傷害。
- [ ] 平均 `>= 1.00x` 時獎勵正常；平均 `< 1.00x` 時經驗、金錢、法寶經驗、絕招經驗與一般掉落皆為零。
- [ ] 持有活物與虛擬敵人都不會複製卡片；戰敗、逃跑、切圖與讀檔後也會正確清理。
- [ ] 同時啟用「全魔物靈契」時，原生靈契成功後應顯示 `delegated captured challenge card`，並由該 MOD 交換成契靈卡；不得同時留下來源卡或重複發卡。自由挑戰本身不解鎖收妖資格。
