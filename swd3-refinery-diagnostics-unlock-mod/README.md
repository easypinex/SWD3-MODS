# 軒轅劍參 Steam 版：煉化條件診斷與全限制解除 MOD

這是獨立 MOD，不會併入武器熟練度 MOD。支援 Steam 高清版 4.0.x。

## 功能

- 解除東方與西方煉化的「成品最多高於賽特 6 級」限制。
- 選滿兩項材料後，以完整診斷卡顯示材料名稱、東西方真實成品名稱與等級。
- 目前預覽的方向會以單次清晰的黃橘色文字顯示，非目前方向維持正常淺黃色，不再使用會造成中文筆畫重影的偏移重疊繪製。未取得封神壇時會跟隨 `End` 的隱藏東方預覽；取得後則跟隨原版 `Q／左方向鍵` 選東方、`E／右方向鍵` 選西方。
- 顯示原版最低賽特等級：`max(1, 成品等級 − 6)`。
- 顯示封神壇是否已取得；未取得時仍須按鍵盤 `End` 使用原版隱藏東方預覽。
- 若結果為黏怪，提示這是配方結果，不是等級不足。
- 戰鬥中記錄 `BattlePlayers[1]` 的等級，面板顯示「最近戰鬥 Lv.X」；首次同步前顯示「尚未同步」。此資料隨各存檔保存。
- 診斷面板會從材料預覽完成後持續顯示，直到取消、正式煉化、切換地圖或進入戰鬥，不再受短暫計時限制。
- 所有自訂中文標籤都由 MOD 的 UTF-8 `TYPE 0` 文字資料註冊，再經 `StringDB` 繪製；若文字資料載入失敗，會自動改用完整 ASCII 標籤，不再留下無意義的零碎文字。

MOD 不會贈送封神壇、不支援右 Shift，也不改配方、材料、成品數值、故事旗標或既有道具。

## 運作原理

原版先呼叫 Lua 計算東、西方成品，再由原生程式比較成品與賽特等級。MOD 包裝原有 `OnEvent.Obsolt.main`，預覽完成後只把兩項結果範本的判定等級暫設為 1，讓原生介面建立可合成狀態；到同一幀的選單繪圖事件便立即還原真實等級。

正式按下確認時，MOD 會先再次強制還原，然後交回原版函式。因此材料扣除、增加成品、唯一物品規則、背包容量、動畫、Steam 統計及成就仍由原版流程處理，不會自行複製一次合成。

若 Lua 錯誤、取消、離開選單、切換地圖、進入戰鬥或開始正式煉化，MOD 都會執行還原與清理。控制台只輸出初始化、包裝狀態與還原失敗等必要訊息。

## 成品與生效確認

完成品為 `dist/refinery_diagnostics_unlock.ssmod`，basename 固定為 `refinery_diagnostics_unlock`。通用建置、反解、安裝與完整重啟步驟見 [封裝與安裝](../docs/knowledge/packaging-and-installation.md)，v1.5 雜湊與版本證據見 [PACKAGING-NOTES.md](PACKAGING-NOTES.md)。

Console 看到下列訊息代表包裝器已安裝：

```text
[RefineryDiagnostics] Installed refinery wrapper; East/West level limits unlocked
```

選滿兩項材料且面板繪圖事件成功執行時，控制台另會輸出同一配方的完整可讀診斷，例如：

```text
[RefineryDiagnostics] 材料：材料甲 + 材料乙 | 西方：成品甲 Lv.20（原版賽特 Lv.14） | 東方：成品乙 Lv.30（原版賽特 Lv.24） | 等級限制已解除 | 封神壇：尚未取得；按鍵盤 End 預覽東方結果
```

## 實機驗收重點

1. 選滿兩項材料後面板持續出現；離開煉化後不殘留。
2. 未取得封神壇時按 `End`，面板標示「東方預覽已啟用」。
3. 東、西方高等級結果都能以原版確認流程煉化，且只扣兩份材料、只增加一份成品。
4. 成品的正式等級不會變成 1；連續更換配方結果也不會受前一次預覽影響。
5. 若面板殘留、配方改變、成品等級變 1 或發生重複煉化，請立即停用本 MOD，該版本不可發布。
6. 預設西方結果為清晰黃橘色，東方結果為正常淺黃色；按 `End` 進入隱藏東方預覽後，兩者顏色必須完全對調，文字不得出現偏移重影。
7. 已取得封神壇時，`Q／左方向鍵` 必須使東方變成清晰黃橘色，`E／右方向鍵` 必須使西方變成清晰黃橘色。
