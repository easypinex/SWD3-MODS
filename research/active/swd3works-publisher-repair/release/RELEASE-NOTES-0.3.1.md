# SWD3 MOD Studio 桌面版 0.3.1

- 設定頁新增「接管 Steam 啟動入口」：備份原 `SWD3Works.exe` 後改由原路徑開啟 MOD Studio。
- 可查詢接管狀態、重新接管新版位置、還原原版入口、開啟原工具及啟動遊戲。
- 入口替換與還原均核對雜湊；未知版本、備份損壞和路徑連結會停止操作。還原保留備份與草稿。
- 遊戲執行中會提示先正常關閉，避免原工具無聲退出或重複啟動遊戲。
- 沿用 0.3.0 Steam 工作者與現有草稿／發佈歷史。Setup 不自動接管。

先把完整套件解壓至固定且位於遊戲外的資料夾，完成 Setup，再從「設定與診斷」選擇 `swd3.exe`、按接管。更新或移動套件後，從新位置重新接管。

Windows 10/11、Framework 4.8、Python 3／zstandard，以及已驗證的 Steam 高清版遊戲配套。未簽章；不含遊戲 DLL 或帳號資料。Steam 更新／驗證可能還原入口；遇到新版原工具雜湊時，需先重新驗證支援。

已完成 15 項入口隔離檢查、13 項桌面及 32 項工作者測試；本機實測原入口轉接、還原、再接管與作品查詢。Steam「開始」按鈕、Overlay、遊玩時間及 DLC 管理未在本次測試；遊戲當時仍在執行，沒有中斷使用中的遊戲。
