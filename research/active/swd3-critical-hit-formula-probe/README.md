# 爆擊傷害唯讀量測探針

> 研究來源：本頁保存所列版本的操作與證據。是否重用、知識去向及未解問題，先查[研究清冊](../../README.md)；通用能力依[知識庫](../../../docs/knowledge/README.md)，不因歸檔或 mock 通過擴張為正式支援。

此探針只為確認 Steam HD 4.0.5 的玩家**普通攻擊**爆擊傷害機制而設計。它不改寫 `OnEventValue.BeCriticalHit`、角色數值、敵人數值、武器、存檔或戰鬥指令。

每次玩家對敵人的普通攻擊，Console 會記錄：原生輸入與 Lua 最終爆擊旗標、雙方等級、目前武器與攻擊效果、目標 HP 的判定前後值，以及量得的傷害。原生 HP 寫入晚於 `BattlePlayerAI_after`，探針會保留樣本並在後續 `Battle_DrawBGI` 或下一次攻擊前再量測。它每場最多記錄 40 筆，避免洗版。

## 目前取樣限制

**待驗證；2026-09-06 整理。** 下方 v0.1／v0.2 操作與 mock 是歷史設計，尚無完整武器樣本。後續時序研究已確認 `Battle_DrawBGI` 不能在原版手動模式當作穩定逐幀入口，`BattleCriticalHitRate` 也會在防禦出現。重用本工具前須重新核對樣本歸屬；不得為了取得 BGI 設定 `BattlePlayerAI_mod`。詳見[時序正文](../../../docs/knowledge/battle-events-and-timing.md)。本次沒有改探針來源或推導新傷害公式。

## 實機操作

1. 使用可丟棄的測試存檔，僅啟用本探針與要驗證的自由挑戰 MOD；停用任何收妖 bridge／舊戰鬥探針。
2. 完全關閉遊戲，先開 `SS2DConsole.exe`，再開遊戲；應看到 `armed: read-only player normal-attack samples`。
3. 建立一隻、五項均為 `1.0x` 的牛魔王挑戰。妮可裝短木弓，賽特採當前劍；兩人都只選普通攻擊。
4. 對每人至少累積 20 次普通攻擊。看到爆擊的畫面數字後，保存附近兩行 `roll`／`result` Console 訊息。
5. 若 `result` 的 HP 差與畫面數字相同，即可比較普通與爆擊的實際傷害；若 HP 差未在 `BattlePlayerAI_after` 時點更新，保留完整 Console 記錄，該探針只報告時序未確認，不假造公式。

## 可回答與不能回答的問題

- **可回答（待實機）**：短木弓的爆擊是否固定量得 9,999；賽特劍擊是否為多段總傷；爆擊旗標是否由 native 預先給定，或由原版 Lua 的等級骰補上。
- **不能單靠此探針回答**：native 內部的完整組語言公式、隱藏亂數種子或未暴露的資料欄位。若樣本顯示不同武器的爆擊類型不同，還需要各武器類型的重複量測。

## 驗證

在本專案根目錄執行：

```powershell
.\tests\run-tests.ps1
```

封裝後必須反向解包並比對來源與產物雜湊；不直接修改遊戲安裝目錄。

## 目前驗收

- **已通過，2026-09-04，v0.2：** Lua 語法與 mock runtime。mock 分別重現普通攻擊 `30,000 → 29,997`（量得 3）及已標為爆擊的 `30,000 → 20,001`（量得 9,999）。
- **已通過，2026-09-04，v0.2：** `swd3_critical_hit_formula_probe.ssmod` 已反向解包；manifest SHA-256 為 `44F05F0A5923DE9DD9855DBDB8548F4CF01EAB54DBD7377800DA8A7DB14958E1`，Lua SHA-256 為 `CBAB59D72F6CE11610AC67B4303018FF06B211B6369FB7F9533F08331D52E562`，均與來源相同。
- **已實測，2026-09-04，v0.1：** 真實戰鬥顯示 `BattlePlayerAI_after` 早於 native HP 寫入；v0.2 因此改由後續 `Battle_DrawBGI` 或下一次攻擊前結算。
- **待實機：** 仍需依上方步驟取得短木弓與賽特劍擊的真實樣本；在這之前，不把固定 9,999 推廣成所有角色、武器或技能的完整公式。
