本專案只驗證一條完整路徑：原生靈契收服一隻蛇（ID `102`）後，是否能安全地把原生新增的 ID `102` 移除，改為一張已在 MOD 載入期註冊的蛇卡 ID `9004`。

前提是[靜態物品註冊探針](../swd3-static-item-registry-probe/README.md)已實測證明載入期新卡可安全反白。本探針不在戰後新增 `ItemTemp`；ID `9004` 在 Lua 頂層載入時，由原版黏怪卡 UI 欄位與蛇的戰鬥資料組合而成。

## 已實測結論

**已實測，Steam HD 4.0.5，2026-09-03。** 原生靈契成功收服自訂戰場的蛇後，遊戲先新增原生 ID `102`；探針在 `Battle_RestoreItem` 只於總數高於戰前基線時移除一張 ID `102`，再新增載入期靜態 ID `9004`。ID `9004` 可正常在物品欄反白、返回地圖，最後由 F1 安全清除。此單隻「原生收妖 → 靜態卡交換」完整路徑成立。

此結論尚不涵蓋護駕啟用、存檔讀寫、所有敵人映射或批量卡資料。

## 安全規則與操作

- 只啟用本探針；停用全魔物收妖、快取重建與靜態註冊探針。
- 使用可丟棄的測試存檔，絕不保存。
- 在安全地圖按 **F2**，戰鬥中只用「靈契」收服蛇，勿正常擊殺。

- 離開物品欄按 **F1** 清除，確認 `removed=1`；若閃退或交換失敗，直接結束遊戲且不保存。
