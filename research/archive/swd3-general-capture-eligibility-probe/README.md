# 一般戰鬥靈契資格探針

> 歷史實驗：本頁保存所列版本的操作與證據。是否重用、知識去向及未解問題，先查[研究清冊](../../README.md)；通用能力依[知識庫](../../../docs/knowledge/README.md)，不因歸檔或 mock 通過擴張為正式支援。

本 MOD 專門驗證「一般遭遇的非活物」與「帶原生劇情限制的敵人」能否在**目前這場戰鬥**暫時通過靈契的前置資格。原生靈契成功時，探針會依開戰前的背包基線，將原生新增的來源物品安全交換為已靜態註冊的對應活物卡；它不調整敵人等級，也不寫入存檔。

在**地圖上**按 **Home** 後，探針會巡覽完整 193 筆戰鬥目錄，並對可安全對應 `ItemTemp + Race` 的項目立刻套用資格（本機 Steam HD 4.0.5 為 183 筆、15 個種族；另 10 筆跳過），確保早於原生建立敵人及靈契目標 UI 的資格快取；它只改目錄中敵人對應的原版資料：

- 暫設 `ItemTemp[敵人 ID].IT_12 = true`；
- 暫時移除 `IT_06`；
- 暫設該敵人種族的 `Race.catch = true`。

戰鬥結束、切圖或重新進入遊戲時，所有欄位都會從逐欄快照還原。bridge 生效期間不得重複按 Home；因此它不會永久開放資格，也不碰戰鬥內 HP／等級、物品或存檔。

## 操作與驗收

1. 僅使用可丟棄的測試存檔，保持「全魔物靜態卡庫」啟用；不要啟用舊收妖探針。
2. 在地圖按 **Home**。Console 應顯示 `pre-battle bridge active: sources=183, races=15, skipped=10`。
3. 立刻進入一場**原生一般遭遇**，找一個原先無法選取的非活物目標。Console 應顯示 `Battle_EnemyInit observed under pre-battle bridge`。
4. 使用「靈契」開啟選目標。目標不再顯示紅色 X，即代表前置資格成功；只驗證選取可取消靈契。要驗證交換則只收服一隻目標，且**不可存檔**。
5. 若要驗證完整收妖，僅可收服一隻目標。Console 必須依序出現 `native Battle_Dead(mode=2)`、`capture exchange confirmed` 與 `pre-battle bridge restored (Battle_RestoreItem)`；再於物品欄反白新的靜態卡一次，仍**不可存檔**。

## 判讀與界線

| 結果 | 意義 |
| --- | --- |
| 一般非活物可被靈契選取 | **已實測**：原生 UI 與捕捉前置旗標可由進戰前 bridge 暫時開放。 |
| 收妖後顯示 `capture exchange confirmed` | 原生新增物品已依基線交換成靜態卡；可進行一次物品欄反白驗收。 |
| 劇情首領仍有紅色 X，但一般敵人成功 | 劇情首領可能另受等級差或 native 專屬限制，下一階段以獨立首領探針驗證；不要加大本探針權限。 |
| Home 預備後仍無法選取 | 請提供 `pre-battle bridge active`、`Battle_EnemyInit observed` 與戰鬥初始紀錄；不改原版流程前先定位缺少的 native 條件。 |
| 正常離開戰鬥後沒有 restored 訊息 | 立刻結束遊戲且不保存，回報完整 Console；此版本不可繼續測試。 |

## 已知狀態

**已實測一般遭遇，Steam HD 4.0.5，2026-09-03。** 野猴（ID `106`）在原生一般遭遇中原本不是活物卡。地圖按 Home 後，它可由原生靈契收服；原生新增來源 ID `106` 後，v0.4 依戰前基線刪除該新增物並加入靜態卡 `10046`。`10046` 已在物品欄正常反白，且戰後 bridge 已還原。這不等同劇情首領已驗收：高於隊伍 12 級的敵人仍可能因原生等級差得到 0% 成功率；本探針刻意不動等級，避免把一般資格測試和首領平衡改寫混為一談。

執行自動檢查：`./tests/run-tests.ps1`。本專案是研究探針，未完成包含收妖、交換、存檔與停用的實機矩陣前不可發布。
