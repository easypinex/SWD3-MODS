# 活物挑戰：原生對話容器驗證

> 歷史實驗：本頁保存所列版本的操作與證據。是否重用、知識去向及未解問題，先查[研究清冊](../../README.md)；通用能力依[知識庫](../../../docs/knowledge/README.md)，不因歸檔或 mock 通過擴張為正式支援。

此為一次性實機探針，不包含活物選擇或戰鬥功能，也不寫入存檔。

輸入與 modal 的通用結論見 [UI、輸入與原生選單](../../../docs/knowledge/ui-input-and-native-menu.md)，研究探針規則見 [測試與驗證](../../../docs/knowledge/testing-and-verification.md)。

## 操作

1. 啟用本 MOD，停用 `live_card_battle.ssmod`，避免兩者同時處理 F9。
2. 在安全的地圖開啟物品籃，按 F9。
3. 確認是否同時看見原生對話文字與黃色 `MOD 繪製仍在運作`。
4. 嘗試點原物品籃、切換分類、按方向鍵與點地圖；記錄是否仍穿透。
5. 再按 F9，確認對話層消失並可正常回到物品籃。

## 驗收結果

- 若四項皆通過，才能以原生對話層承載完整的活物挑戰畫面。
- 任一項失敗，立即停用本探針；正式 MOD 保持原狀，不把這個容器方案併入。
